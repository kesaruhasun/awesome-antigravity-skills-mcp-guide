# 🤝 Contributing to Awesome Antigravity & MCP Guide

Thank you for your interest in contributing! This project thrives on community contributions to keep skills, MCP servers, and cloud resources up-to-date.

---

## How to Contribute

### 1. Adding a New Agent Skill
When proposing a new skill or plugin:
- Verify that the skill adheres to the [Agent Skills Specification](https://agentskills.io/).
- Include the official source/repository link.
- Provide a concise description of what the skill does and when an agent should trigger it.

### 2. Adding an MCP Server
When submitting an MCP server:
- Ensure it implements the [Model Context Protocol (MCP)](https://modelcontextprotocol.io/).
- Provide an example configuration snippet for `mcp_config.json`.
- State whether the server runs locally (stdio/npx/python) or as a remote service (SSE/HTTPS).

### 3. Adding a Free Cloud / VPS Tier
- Must offer a legitimate, verifiable free tier or student credit.
- Detail compute, RAM, storage, and egress quotas clearly.

---

## Submission Checklist

- [ ] I have read and followed the markdown formatting style.
- [ ] Links and URLs are active and point to primary official sources.
- [ ] No private credentials, API keys, or sensitive data are included.
