## 6. Step-by-Step Application & Approval Guide

```
┌────────────────────────────────────────────────────────────┐
│              STUDENT PACK VERIFICATION FLOW                │
├────────────────────────────────────────────────────────────┤
│ 1. Connect University Email (.edu or campus domain)        │
│ 2. Turn on Two-Factor Authentication (2FA)                 │
│ 3. Update GitHub Profile Name to Match Student ID          │
│ 4. Take Clear Photo of Student ID / Proof of Enrollment    │
│ 5. Submit at education.github.com/pack                     │
└────────────────────────────────────────────────────────────┘
```

### Pro-Tips for Instant Verification:
1. **Camera Location:** Ensure browser location access is permitted when taking the photo of your ID card. Verification checks that your IP matches your institution's geographic region.
2. **Document Requirements:** If your student ID doesn't show a future expiration date, upload an official semester class schedule, transcript, or tuition fee receipt showing the current academic term.
3. **Profile Alignment:** Ensure your GitHub profile display name matches the legal name printed on your school documents.

## 7. How to Redeem DigitalOcean & Azure Credits

### Redeeming DigitalOcean:
1. Navigate to your [GitHub Student Developer Pack benefits dashboard](https://education.github.com/pack/offers).
2. Find the **DigitalOcean** card and click **Get Access / Unique Promo Link**.
3. Create a new DigitalOcean account (or sign in).
4. Verify your identity with a payment method (PayPal or credit card — you will not be charged if credits are applied).
5. The **$200 promo credit** will automatically appear under **Billing -> Promo Credits** and remain valid for 12 months.

### Redeeming Microsoft Azure:
1. Go to the Azure Student Offer via the GitHub Student Pack page.
2. Sign in with your GitHub account or university email.
3. Complete the verification flow (SMS verification required, **no credit card needed**).
4. Your **$100 Azure credit** will activate immediately in the Azure Portal.
